# MASTER IMPLEMENTATION PROMPT — MANHUNTER

Implement the first commercial-ready revenue-loop system inside the existing Ordvela repository.

## Strategic Context
ORDVELA remains the master brand.
Ordvela Intelligence is the product family.
Manhunter is the current working product/system name.

Do not create a new repository, domain, master brand or unrelated product architecture.

Core loop:
REAL DEMAND → OPPORTUNITY → SCORE → EXECUTION → DEMO → DISTRIBUTION → DEAL → REVENUE

## Three Layers
Layer 01 Intelligence: find real demand, preserve evidence, detect intent, extract opportunities and score them.
Layer 02 Execution: turn selected opportunities into solution blueprints, prototypes, deployments and demos.
Layer 03 Distribution: prepare a personalized final message, require human approval, send manually in V0 and capture outcomes.

## Philosophy
Build for commercial use from the beginning, but optimize for speed to revenue.

Do not build a generic CRM, generic scraper, mass outreach bot, unnecessary billing complexity, speculative platform features or unnecessary branding.

## Technical Principles
1. Provider-independent core.
2. Adapter-based sources.
3. Server-side secrets.
4. BYOK-ready.
5. Cloudflare-friendly.
6. Small testable modules.
7. Preserve raw evidence.
8. Explainable scoring.
9. Human-in-the-loop outreach.
10. Workspace, usage hooks, provider abstraction and feature flags from V0.

## Implementation Order
First make Screen 1 useful.
Then connect Screen 2.
Then connect Screen 3.

Do not build all theoretical features before the first end-to-end workflow works.

## Required End-to-End Demo
1. ingest a real public demand signal
2. normalize and store evidence
3. derive an opportunity
4. score and rank it
5. open original evidence
6. select opportunity
7. create solution blueprint
8. execute a constrained prototype
9. deploy a demo
10. generate a final message
11. require human approval
12. record contact outcome

## Quality Bar
Prefer a narrow workflow that actually works over a broad mockup.

Every major operation needs loading, success, explicit failure, safe retry where applicable and auditability.

## Final Rule
The objective is not an impressive AI dashboard.

The objective is a repeatable machine for:

FIND → BUILD → SHOW → SELL.

Ship the smallest real version that can be used to generate revenue.
