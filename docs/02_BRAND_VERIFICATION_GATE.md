# ORDVELA — Brand Verification Gate

## Objective

Determine whether ORDVELA can proceed from selected working name to an externally committed brand.

## Gate A — Domain

Check directly with a registrar/WHOIS provider. At minimum record:

- ordvela.com
- ordvela.co
- ordvela.io
- ordvela.ai
- ordvela.id
- ordvela.co.id

For each: `AVAILABLE`, `REGISTERED`, `PARKED`, `ACTIVE USE`, or `UNCERTAIN`.

Search-engine absence is not proof of availability.

## Gate B — Social Handles

Directly check from authenticated or authoritative platform surfaces:

- Instagram
- X
- LinkedIn
- GitHub
- TikTok
- YouTube
- Threads

Record exact handle status and whether the account is active, dormant, personal, unrelated, or commercial.

## Gate C — Trademark

Perform preliminary searches in:

- DGIP / PDKI Indonesia
- USPTO
- EUIPO
- WIPO Global Brand Database

Search both exact and similarity/phonetic variants. Prioritize technology-relevant classes, especially Class 9 and 42, and any other classes actually relevant to the intended business model.

## Search Method

For every database:

1. exact `ORDVELA`
2. spacing/word variants where supported
3. phonetic/similar variants
4. relevant goods/services
5. owner/entity context
6. application and registration status
7. filing/priority dates

## Classification

Use only these statuses:

- `CLEAR-SURFACE` — no material result found in the checked scope
- `CONFLICT` — material collision found
- `UNCERTAIN` — result requires human/legal interpretation
- `NOT-CHECKED` — verification not performed

Do not call a candidate `brand-safe`, `trademark-safe`, or `legally cleared` based on a surface search.

## Final Gate

ORDVELA can move to internal `BRAND LOCK` only after required checks are documented and no unresolved material conflict remains. Formal legal clearance, where needed, remains the responsibility of qualified counsel.

## Audit Record

Every check must record:

- date/time
- source
- query
- jurisdiction/platform
- result
- evidence URL or reference
- interpretation
- reviewer

This creates an auditable ownership trail.
