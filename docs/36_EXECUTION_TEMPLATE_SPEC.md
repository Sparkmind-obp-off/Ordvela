# ORDVELA INTELLIGENCE — Execution Template Specification
Status: V0 CANONICAL

## Principle
Constrained templates beat unrestricted autonomous coding for the first production loop.

## Blueprint
opportunity_id · problem · target_outcome · solution · features · constraints · assumptions · stack · deployment_target · acceptance_criteria

## Template Contract
Define inputs, generated artifacts, validation checks, deployment method, known failure modes and rollback/cleanup path.

## Demo Standard
Small, credible, functional and directly relevant to the observed problem.

## Safety
Generated artifacts receive no production secrets by default. Deployment credentials remain server-side.
