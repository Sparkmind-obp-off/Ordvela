# Manhunter — Operating SOP

Status: V0 OPERATING STANDARD
Date: 2026-10-08

## Daily Loop
1. Discover — run enabled source adapters.
2. Review — inspect high-score opportunities.
3. Verify — open original evidence.
4. Select — choose clear, valuable, feasible and reachable opportunities.
5. Execute — create a small relevant solution/demo.
6. Deploy — publish a stable shareable URL.
7. Prepare Message — generate a concise evidence-based message.
8. Human Review — verify accuracy, relevance, claims, tone, URL and target.
9. Contact — send manually.
10. Record Outcome — reply, qualified, proposal, won/lost or follow-up.
11. Learn — review sources, patterns, solutions and messages against conversations and revenue.

## Daily Priority
Prefer 5–10 strong opportunities over hundreds of weak leads.

## Revenue Discipline
If a workflow does not move toward DISCOVER → DEMO → CONTACT → DEAL, it is not a V0 priority.
