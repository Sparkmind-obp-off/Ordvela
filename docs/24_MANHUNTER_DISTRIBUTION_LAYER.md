# Manhunter — Layer 03: Distribution / Final Message

Status: V0 SPEC
Date: 2026-10-08

## Objective
Move a relevant solution from the system to the person who expressed the demand.

## Pipeline
DEMO → TARGET → MESSAGE DRAFT → HUMAN REVIEW → SEND → FOLLOW-UP → OUTCOME

## Message Principle
Demo-first, evidence-first, relevance-first.

Avoid generic service pitches, mass outreach, fake personalization, inflated claims and pressure tactics.

Prefer referencing the actual demand, showing what was built, explaining relevance briefly and offering a low-friction next step.

## V0
Sending is manual.

The system prepares target summary, source evidence, demo URL, message draft, suggested follow-up and outcome state.

## Outcome States
NEW → CONTACT_READY → CONTACTED → REPLIED → QUALIFIED → PROPOSAL → WON/LOST, with FOLLOW_UP as a reusable state.

## Feedback
Distribution outcomes feed back into scoring and source evaluation. High-converting sources and patterns gain priority; noisy sources lose priority.
