# ORDVELA INTELLIGENCE — Security and Trust
Status: V0 CANONICAL

## Rules
1. Secrets never enter client bundles.
2. API keys are never logged.
3. Raw evidence is separate from derived intelligence.
4. External actions require explicit authorization.
5. Outreach is human-approved in V0.
6. Actions are attributable to workspace/user.
7. Provider failures cannot silently corrupt commercial state.
8. Demos cannot expose private credentials or private source data.

## Abuse Boundaries
No credential harvesting, unauthorized private-data collection, platform-control bypass, deceptive impersonation or mass unsolicited messaging. Respect source terms, law and provider policies.

## Audit
Ingestion, opportunity creation, score changes, execution, deployment, message generation, approval and outcomes.
