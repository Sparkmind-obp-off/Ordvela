# ORDVELA INTELLIGENCE — V0 Acceptance Tests
Status: RELEASE GATE

## E2E test
1. Capture one real public signal.
2. Preserve source URL and raw evidence.
3. Normalize and deduplicate it.
4. Create an opportunity.
5. Show evidence and score explanation.
6. Select the opportunity.
7. Create a solution blueprint.
8. Generate or build a constrained demo.
9. Deploy and obtain a reachable demo URL.
10. Generate a relevant message.
11. Require explicit human approval.
12. Record contact/outcome.
13. Confirm the outcome is queryable later.

## Quality gates
- No raw API key appears in browser output or logs.
- No external message is sent without approval.
- Original evidence remains recoverable.
- Failed jobs are visible and retryable.
- Duplicate signals do not create uncontrolled duplicate opportunities.
- Demo does not expose private credentials or private source data.

## Commercial gate
V0 is not declared successful because screens exist. It passes only when the loop can be used against real demand and produce a measurable commercial outcome.
