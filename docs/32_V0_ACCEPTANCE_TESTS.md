# ORDVELA INTELLIGENCE — V0 Acceptance Tests
Status: RELEASE GATE

## End-to-End
1. Capture a real public signal.
2. Preserve URL and raw evidence.
3. Normalize and deduplicate.
4. Create an opportunity.
5. Show evidence and score explanation.
6. Select it.
7. Create solution blueprint.
8. Generate/build constrained demo.
9. Deploy reachable demo URL.
10. Generate relevant message.
11. Require explicit human approval.
12. Record contact/outcome.
13. Query the outcome later.

## Security Gates
No raw API keys in browser output or logs. No external message without approval. Original evidence remains recoverable. Failed jobs are visible and retryable. Duplicate signals do not create uncontrolled duplicates. Demos expose no private credentials/source data.

## Commercial Gate
Screens do not equal success. V0 passes only when the real loop produces a measurable commercial outcome.
