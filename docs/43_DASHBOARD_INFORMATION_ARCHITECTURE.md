# ORDVELA — Dashboard Information Architecture
Status: CANONICAL / V0

## Shell
Global header: workspace, system status, usage and account.
Primary nav: Demand Feed / Opportunities / Execution / Distribution / Outcomes.
Secondary: Settings / Providers / Audit.

## Demand Feed Layout
Filters → ranked opportunity list → selected opportunity panel.

## Opportunity Detail Layout
1. Problem and desired outcome.
2. Score and score explanation.
3. Original evidence.
4. Commercial signals.
5. Recommended action.
6. Execution CTA.

## Execution Layout
Opportunity context → blueprint → generation/build progress → validation → deployment → demo.

## Distribution Layout
Target → evidence → demo → message → approval → contact → follow-up.

## Outcomes Layout
Pipeline → outcome detail → revenue → feedback.

## Rule
Navigation reflects the revenue loop, not internal database tables.
