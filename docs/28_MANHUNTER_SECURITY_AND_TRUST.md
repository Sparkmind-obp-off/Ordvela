# Manhunter — Security & Trust

Status: V0 BASELINE
Date: 2026-10-08

## Core Rules
1. Secrets never enter client bundles.
2. API keys are never logged.
3. Raw evidence is separate from AI-derived content.
4. External actions require explicit authorization.
5. V0 outreach is human-approved.
6. Automated actions are attributable to a workspace/user.
7. Provider failures cannot silently corrupt commercial state.
8. Demo deployments cannot expose private credentials or private source data.

## Data Classes
Public source evidence, derived intelligence, workspace data, provider secrets and commercial outcome data.

Apply least privilege.

## Abuse Prevention
Do not optimize for mass unsolicited messaging, credential harvesting, bypassing platform controls, unauthorized private-data collection or deceptive impersonation. Respect source terms, applicable laws and provider policies.

## Audit Trail
Record signal capture, opportunity creation, score changes, execution start, deployment, message generation, human approval and contact outcomes.
