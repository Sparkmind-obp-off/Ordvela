# ORDVELA — User & Customer Journey
Status: CANONICAL / V0

## Operator Journey
ENTRY → CONNECT PROVIDERS → DISCOVER → REVIEW → SELECT → BUILD → DEMO → REVIEW MESSAGE → CONTACT → RECORD OUTCOME → LEARN

### First Session
1. Create/sign into workspace.
2. Confirm provider configuration or BYOK.
3. Run/enable first source.
4. Receive first signals.
5. Review evidence.
6. Select one opportunity.
7. Produce first demo.
8. Approve a message.
9. Record the result.

## Customer Journey
PUBLIC NEED → DISCOVERY → RELEVANT DEMO → CONTACT → CONVERSATION → QUALIFICATION → PROPOSAL → DEAL → REVENUE

## Journey Principle
The operator should never need to understand the internal architecture to complete the commercial loop.

## Friction Metrics
Track time-to-first-opportunity, time-to-first-demo, time-to-first-contact, reply rate, qualification rate, proposal rate and win/revenue rate.
