# Manhunter — Roadmap

Status: EXECUTION BASELINE
Date: 2026-10-08

## V0 — FIND
Build source adapters, normalized evidence, demand extraction, intent, opportunity scoring, opportunity feed and evidence view.

Success: a human can inspect ranked opportunities and identify genuinely actionable demand.

## V1 — BUILD
Add solution blueprint, constrained execution templates, BYOK provider abstraction, prototype generation, Cloudflare deployment, demo URL and execution history.

Success: a qualified opportunity can become a credible demo quickly.

## V2 — SHOW / SELL
Add distribution screen, personalized message generation, human review, follow-up states, outcome tracking and conversion analytics.

Success: opportunity → demo → conversation is measurable.

## V3 — COMMERCIAL
Add authentication, workspaces, usage/credits, BYOK onboarding, hosted provider mode, billing, plans, self-serve onboarding and API boundary.

## V4 — SCALE
Only after evidence: more sources, advanced scoring, team workflows, agency mode, API products and independent layer packaging.

## Anti-Overbuild Gate
Every feature must improve finding demand, building the solution, reaching the demand, conversion or revenue.
