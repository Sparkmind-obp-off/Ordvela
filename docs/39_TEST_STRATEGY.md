# ORDVELA INTELLIGENCE — Test Strategy
Status: V0 CANONICAL

## Layers
1. Unit — scoring, normalization, transitions and validation.
2. Contract — provider adapters and API schemas.
3. Integration — persistence plus provider boundaries.
4. E2E — real signal through demo and approved distribution.
5. Regression — security, naming, state and data integrity.

## Critical Invariants
No secret leakage. Workspace isolation. Raw evidence preservation. Repeatable ingestion where defined. Explainable scores. Valid state transitions. Human approval before contact. Outcome persistence.

## Release Rule
A green UI is insufficient. The revenue loop must be executable and observable.
