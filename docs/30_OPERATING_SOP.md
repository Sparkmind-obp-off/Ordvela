# ORDVELA INTELLIGENCE — Operating SOP
Status: V0 CANONICAL

## Daily Loop
1. Discover real demand.
2. Review high-score opportunities.
3. Verify original evidence.
4. Select clear, valuable, feasible and reachable opportunities.
5. Build a small relevant solution.
6. Deploy a shareable demo.
7. Prepare an evidence-based message.
8. Human-review claims, relevance, target and URL.
9. Contact manually.
10. Record outcome.
11. Feed learning back into sources, scoring, solutions and messaging.

Prefer 5–10 strong opportunities over hundreds of weak leads.

## Priority Rule
If workflow does not move DISCOVER → DEMO → CONTACT → DEAL, it is not a V0 priority.

## Source Expansion SOP

Do not optimize for source count. Optimize for **qualified demand per unit of cost and engineering friction**.

For each new provider: verify official access contract → configure minimum credential → run bounded read-only ingestion → preserve evidence/provenance → measure qualified-demand rate → measure opportunity and downstream outcomes → keep, defer or disable based on evidence.

### Meta SOP
Meta is currently **SOFT-HOLD**. Keep adapters intact, run one controlled recovery attempt when valid access is available, do not guess permissions or use unofficial workarounds, and do not let Meta block other source development.

### Paid-source SOP
A paid API is justified when:
**incremental gross value from qualified opportunities > API cost + operational cost + maintenance friction.**
